## 项目概述

Crawler Tool 是一个以 Python 为基础的爬虫工具项目，主要面向网页数据采集、重复信息整理和数据处理练习场景。

该项目用于记录我对爬虫工具开发、命令行交互、数据保存方式和 Python 工程化结构的学习过程。

## 项目背景

在学习网页信息获取和自动化处理的过程中，我希望通过一个实际项目理解爬虫工具的基本工作方式。

这个项目的重点不是追求复杂功能，而是从简单、稳定、可维护的功能开始，逐步扩展为一个可以长期完善的数据采集工具。

## 技术栈

- Python
- HTTP 请求
- HTML 解析
- CLI 命令行工具
- Git
- GitHub

部分解析库、数据导出格式和配置方式仍处于规划阶段，后续会根据项目推进逐步确定。
