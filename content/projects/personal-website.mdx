## 项目概述

个人网站部署实践是当前个人技术展示网站的基础项目，用于集中展示我的项目实践、技术方向和后续文章内容。

项目采用 Next.js、TypeScript 与 Tailwind CSS 构建，整体保持静态化、轻量化和 Vercel 部署友好的结构。

## 项目背景

我希望建立一个长期维护的个人技术主页，用来记录云计算、AI 工程、机器人与自动化方向的学习过程。

相比临时页面，这个项目更关注稳定的内容组织方式、清晰的页面结构和后续可持续扩展的项目档案系统。

## 技术栈

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- MDX
- Git
- GitHub
- Vercel

## 实现内容

- 搭建 Next.js App Router 项目结构
- 使用 TypeScript 管理组件和项目数据类型
- 使用 Tailwind CSS 构建响应式页面样式
- 完成首页、项目档案页和项目详情页
- 接入 MDX 项目内容系统
- 通过 GitHub 与 Vercel 完成部署流程

## 当前状态

当前网站已经完成第一版首页、项目列表页和项目详情页，项目内容可以通过本地 MDX 文件维护。

后续内容会继续以小步迭代的方式补充，优先保证页面稳定、结构清晰和部署流程可靠。

## 问题与解决

项目推进过程中主要关注页面结构、内容维护方式和构建兼容性问题。

目前已经将项目数据逐步迁移到 MDX 内容系统中，并通过构建检查确认项目列表页与详情页可以正常生成。
